# Interactive H-Bridge Learning Presentation

An animated interactive educational module explaining DC motor control using an H-Bridge circuit.

## 🔗 Live Demo
https://withered-king-5438.abdalahbesho.workers.dev/

## 🎯 Educational Objectives
- Understand H-Bridge structure
- Visualize current flow
- Forward & Reverse motor control logic
- Robotics motor driving fundamentals

## 👨‍🏫 Target Audience
- Robotics beginners
- STEM students
- Embedded systems learners
