# Robotics Simulation Platform

A 3D interactive robotics simulator designed for educational environments.

## 🔗 Live Demo
https://robot.abdalahbesho.workers.dev/

## 🚗 Included Systems
- Line Follower Robot Simulation
- Sumo Robot Strategy Simulation
- IR Sensor behavior modeling
- Motor driver logic visualization
- 3D robot assembly guidance

## 🎯 Educational Purpose
This platform helps students understand how robot logic translates into real-world movement and behavior before physical implementation.

## 👨‍🏫 Designed For
- Robotics beginners
- STEM programs
- Engineering foundations courses
