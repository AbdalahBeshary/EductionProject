# Motor & Battery Selection Interactive Module

An engineering-focused interactive module teaching how to properly select motors and batteries for robotics projects.

## 🔗 Live Demo
https://motorbatteries.abdalahbesho.workers.dev/

## 🔧 Topics Covered
- Motor types comparison
- Voltage vs torque relationship
- Current draw calculations
- Battery capacity (mAh) analysis
- Load-based battery matching

## 🎯 Purpose
Help students understand the engineering logic behind selecting the correct power system for robotics applications.

## 👨‍🏫 Suitable For
- Robotics workshops
- STEM education
- Engineering beginners
